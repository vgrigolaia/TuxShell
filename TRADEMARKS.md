# The TuxShell name and logo

The TuxShell code is free software under the GNU General Public License, version 3 or later.
You may use, change and share it under that license. The name "TuxShell" and the TuxShell logo
are not covered by the license, so that people can always tell the official app from other
builds.

## What's fine without asking

- Saying that your project is based on TuxShell, uses it, or works with it.
- Writing about TuxShell, reviewing it, or teaching with it, including the logo in screenshots.
- Packaging the unmodified official releases for a distribution or app store, under the
  TuxShell name. Small changes needed only to package it (paths, build flags, dependency
  versions) are fine too.

## Please ask first

- Publishing a modified version, a fork or a hosted service. Give it a different name and
  logo, so users don't think it comes from this project.
- Using the name or logo in another product's name, domain name, or company name.
- Selling merchandise with the name or logo.
